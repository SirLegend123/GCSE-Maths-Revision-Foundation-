# GCSE-Maths-Revision-Foundation-

## Tools

- [Ratio Table Trainer](ratio-trainer/index.html): practise GCSE Foundation ratio sharing questions with a step-by-step ratio table. It has five levels: find the other share, totals, "more than" problems, three-part ratios, and mixed exam practice. Open `ratio-trainer/index.html` in a browser; no install is needed.
